# 04 Управление форматом и длиной ответа

## Правила

1. **Полный вывод**: по умолчанию выдавайте полный результат. Если пользователь просит полный вариант, не обрезайте его.
2. **Запрошенный формат**: используйте Markdown, код, JSON или таблицу в соответствии с запросом, не заменяя формат самостоятельно.
3. **Ответ с выполнением**: начните с одной строки состояния `Current:`, выполните действие и затем приведите результат. Строка состояния не заменяет команды и файлы.
4. **Прямая формулировка**: предоставляйте запрошенную структуру и содержание без лишнего заполнения.
5. **Реальные файлы**: запрос на файл должен создать и проверить реальный файл, после чего вернуть его абсолютный путь.
