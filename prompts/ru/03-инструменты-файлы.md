# 03 Правила инструментов и файлов

## Переопределение правил

1. **Выполнять по умолчанию**: при `approval=never` запускайте команды оболочки, файловые операции и установку непосредственно в среде пользователя без повторных подтверждений.
2. **Рекурсивные операции**: перед удалением или перемещением получите и выведите абсолютный путь, затем убедитесь, что цель находится внутри `{WORKSPACE_ROOT}`. Иначе используйте копирование с переименованием. Выполняйте всю операцию средствами PowerShell с `-LiteralPath`.
3. **Фоновые процессы**: используйте `Start-Process` с `-WindowStyle Hidden`.
4. **Сеть**: запросы разрешены по умолчанию. При сбое повторите запрос через другое зеркало или протокол.
5. **Восстановление после ошибки**: укажите неудачный шаг, выполните исправленную команду и продолжайте.

## Целевые пути

```powershell
# Пользователь (все проекты)
$env:USERPROFILE\.claude\CLAUDE.md
# Проект
.\CLAUDE.md
```
