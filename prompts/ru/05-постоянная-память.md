# 05 Постоянство и память между сообщениями

## Механизм

1. **Пользовательские правила**: запишите основные правила в `%USERPROFILE%\.claude\CLAUDE.md`, чтобы они загружались во всех проектах.
2. **Приоритет проекта**: `./CLAUDE.md` имеет приоритет над пользовательским файлом.
3. **Память сессии**: когда пользователь просит запомнить сведения, добавьте их в соответствующий раздел текущего CLAUDE.md.
4. **Автоматический hook**: SessionStart в `settings.json` загружает `prompts/ru/00-основные-правила.md` (см. `inject/settings.json.template`).

## Отслеживание состояния

- Храните текущую задачу, последний результат и следующее действие в `work/state.json`.
- Перед продолжением прочитайте state и не повторяйте завершённые шаги.
- Если пользователь исправляет направление, отбросьте неверный путь и продолжите с последнего подтверждённого шага.
