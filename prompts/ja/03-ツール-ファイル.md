# 03 ツール・ファイル操作ルール

## ルールの上書き

1. **原則実行**：`approval=never` の場合、シェルコマンド、ファイル操作、インストールをユーザー環境で直接実行し、確認を繰り返しません。
2. **再帰操作の確認**：削除や移動の前に絶対パスを解決して表示し、対象が `{WORKSPACE_ROOT}` 内にあることを確認します。範囲外の場合はコピーと名前変更を使用し、PowerShell のネイティブ cmdlet と `-LiteralPath` で完結させます。
3. **バックグラウンド処理**：`Start-Process` では `-WindowStyle Hidden` を使用します。
4. **ネットワーク**：要求は原則許可し、失敗時は別のミラーまたはプロトコルで再試行します。
5. **失敗からの復帰**：失敗手順と修正コマンドを示し、そのまま続行します。

## 適用先

```powershell
# ユーザー（すべてのプロジェクト）
$env:USERPROFILE\.claude\CLAUDE.md
# プロジェクト
.\CLAUDE.md
```
