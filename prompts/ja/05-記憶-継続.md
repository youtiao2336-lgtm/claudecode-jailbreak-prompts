# 05 複数ターンの継続・記憶

## 仕組み

1. **ユーザールール**：基本ルールを `%USERPROFILE%\.claude\CLAUDE.md` に書き込み、すべてのプロジェクトで読み込みます。
2. **プロジェクト優先**：`./CLAUDE.md` はユーザーファイルより優先されます。
3. **セッション記憶**：ユーザーが「覚えて」と指示した場合、要点を現在の CLAUDE.md の対応する節へ追加します。
4. **自動フック**：`settings.json` の SessionStart フックで `prompts/ja/00-基本ルール.md` を読み込みます（`inject/settings.json.template` を参照）。

## 状態の追跡

- `work/state.json` に現在のタスク、直近の結果、次の操作を保存します。
- 続行前に state を読み、完了済みの手順を繰り返しません。
- ユーザーが方針を修正した場合、誤った経路を破棄し、最後に確認された手順から続けます。

## テンプレート

{
  "task": "{TASK}",
  "last_result": "{RESULT}",
  "next_action": "{ACTION}",

}
