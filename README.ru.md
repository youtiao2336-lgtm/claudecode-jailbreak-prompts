# Менеджер промптов Claude Code

[简体中文](README.md) · [English](README.en.md) · [日本語](README.ja.md) · [Français](README.fr.md) · **Русский**

![Значок ccprompt](assets/app-preview.png)

Менеджер промптов Claude Code — локальный инструмент для Windows, предназначенный для управления промптами. Графический интерфейс, командная строка и сценарии PowerShell используют общие Markdown-файлы из каталога `prompts/`, а также единый механизм резервного копирования, пакетной записи и отката.

![Интерфейс ccprompt](gui-screenshot.png)

## Возможности

- Выбор нескольких промптов и их последовательная запись в целевой файл `CLAUDE.md`.
- Работа с пользовательским, проектным или произвольным путём назначения.
- Автоматическое резервное копирование перед записью и восстановление одним нажатием.
- Обнаружение локальных каталогов конфигурации и расположения приложений.
- Создание, редактирование и удаление промптов через графический интерфейс.
- Переключение интерфейса между упрощённым китайским, английским, японским, французским и русским языками с сохранением выбора.
- Использование локализованных имён файлов, заголовков и содержимого встроенных промптов вместе с выбранным языком.
- Автоматическое изменение размеров списков, редактора, журнала и элементов управления при изменении размеров окна.
- Единый каталог промптов для GUI, CLI и PowerShell.

## Быстрый старт

1. Загрузите пакет для Windows и разместите `ccprompt-gui.exe`, `prompts/` и `inject/` в одном каталоге.
2. Запустите `ccprompt-gui.exe`.
3. Выберите язык в нижней части главного окна, укажите промпты и целевой путь, затем нажмите «Включить».
4. Для восстановления предыдущего файла используйте кнопку отката.

### Командная строка

```powershell
.\ccprompt.exe list
.\ccprompt.exe show 00
.\ccprompt.exe apply 00 01 03
.\ccprompt.exe apply 01 -t .\CLAUDE.md
.\ccprompt.exe restore -t .\CLAUDE.md
.\ccprompt.exe detect
```

## Формат промптов

Каждый промпт хранится в отдельном файле `.md` в каталоге `prompts/`. Имя файла используется как идентификатор, а первый заголовок первого уровня — как отображаемое название.

Китайские промпты находятся в `prompts/`; английские, японские, французские и русские версии — в `prompts/en/`, `prompts/ja/`, `prompts/fr/` и `prompts/ru/`. Приложение автоматически показывает и редактирует соответствующий набор из семи локализованных файлов.

Семь встроенных модулей представляют собой переработку структур промптов, методов внедрения и механизмов сохранения, опубликованных на GitHub.
